# ESG 披露收资工具

面向企业 ESG 信息披露的**汇总数据收资工具**：内置港交所《ESG守则》（13 项主题 / 132 项细分披露点）与沪深北《上市公司自律监管指引——可持续发展报告》（23 项议题 / 315 项细分披露点）指标库，支持按披露标准动态生成填报页签，数据按「报告年度 + 统计范围」归档。

纯前端静态应用，无需后端、无需构建，打开 `index.html` 即可使用；数据保存在浏览器 localStorage。

## 功能

- **基本信息**：公司信息、报告年度、统计范围、办公地点（可增删行）
- **披露标准驱动填报**：勾选港交所 / 财政部 / 沪深北 / ISSB 后，填报区动态生成对应页签，按各标准自身议题结构分组
- **四种填报视图**：按议题区块（卡片）｜定量批量录入（表格式）｜定性集中撰写｜定性/定量（混合型双输入）
- **填报管理**：进度条、议题完成度圆点、指标状态（未填 / 已填 / 待复核，点击状态可标记）
- **同比辅助**：上年值一键引用，自动计算同比并提示 ±30% 以上异常波动
- **提交前校验**：未填指标清单、同比异常清单、港交所「不遵守就解释」未填引导
- **评级映射层**：评级标准（MSCI / CDP / EcoVadis 等）只读校验，不产生额外填报任务；映射关系在 `assets/data.js` 维护
- **Excel 批量导入 / 导出**：导出按标准分表（含基本信息表），填好后可直接导回，按「编号」列匹配写回
- **取数指引**：每张指标卡片可展开「责任部门 / 取数来源 / 留存凭证」建议（按维度默认，可在代码中按指标细化）

## 快速开始

```bash
# 本地直接用浏览器打开
open index.html        # macOS
start index.html       # Windows

# 或起一个静态服务
python3 -m http.server 8000   # 访问 http://localhost:8000
```

## 部署到 GitHub Pages

仓库 Settings → Pages → Source 选 `main` 分支根目录，几分钟后通过
`https://<用户名>.github.io/ESG-disclosure/` 访问。

## 目录结构

```
├── index.html          # 页面骨架
├── assets/
│   ├── styles.css      # 样式
│   ├── data.js         # 指标库（STANDARDS）与评级映射（RATING_MAP / RATING_GAP）
│   └── app.js          # 应用逻辑（localStorage 持久化、渲染、导入导出）
└── vendor/
    └── xlsx.full.min.js  # SheetJS（Excel 读写，已本地化，离线可用）
```

## 指标库维护（assets/data.js）

```js
STANDARDS = {
  hkex: {
    name: '…', basis: '…',
    topics: [{
      id: 't0', name: 'E · 资源利用',
      items: [{
        code: 'H1',        // 指标编号（导入导出按此匹配）
        name: '能源有效使用政策',
        type: 'text',      // num=定量 / text=定性 / mix=定性+定量
        unit: '',          // 定量单位
        req:  '披露要求原文',
        hint: '填写提示',
        g:    '能源管理',   // 一级指标（区块内分组）
        lv2:  '直接能源'    // 二级指标（面包屑）
      }]
    }]
  }
}
```

财政部、ISSB 当前为示例条款，按同一结构补全即可；评级映射 `RATING_MAP` 以「标准:编号 → 评级数组」维护。

## 数据说明

- 数据仅保存在**当前浏览器** localStorage，按报告年度分区存储，切换年度互不干扰；
- 清除浏览器数据会丢失填报内容，请定期用「导出填报结果」备份（导出的 Excel 可直接再导入）；
- 多人协同 / 云端存储需后续接入后端（见路线图）。
